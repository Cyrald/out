# Теоретические основы тензорного анализа {#sec:theory}
Тензорный анализ предоставляет строгий математический аппарат для работы с многомерными данными. В данном разделе приведены основные определения и методы, необходимые для решения поставленных задач.
## Понятие тензора и основные операции {#sec:concepts}
Тензором порядка $N$ называется многомерный массив элементов, индексация которого требует $N$ индексов [@shikin2004]. Скаляр является тензором порядка 0, вектор — порядка 1, матрица — порядка 2. Тензоры более высоких порядков называются гиперматрицами.
Основной числовой характеристикой тензора является его норма Фробениуса, которая вычисляется по формуле ([-@eq:tensor-norm]).
$$ \|\mathcal{X}\|_F = \sqrt{\sum_{i_1=1}^{I_1} \sum_{i_2=1}^{I_2} \dots \sum_{i_N=1}^{I_N} |x_{i_1 i_2 \dots i_N}|^2} $$ {#eq:tensor-norm}
где $\|\mathcal{X}\|_F$ — норма Фробениуса тензора $\mathcal{X}$;
$x_{i_1 i_2 \dots i_N}$ — элемент тензора $\mathcal{X}$;
$I_k$ — размерность тензора по $k$-й моде.
Операции сложения и умножения тензоров определяются поэлементно и через тензорное произведение соответственно. Для сжатия данных ключевое значение имеет операция свёртки и понятие ранга тензора, которое обобщает понятие ранга матрицы на многомерный случай [@kolda2009].
## Методы низкорангового разложения {#sec:decomposition}
Низкоранговое разложение позволяет аппроксимировать исходный тензор $\mathcal{X}$ суммой или произведением тензоров меньшей размерности. Основные методы разложения приведены в таблице [-@tbl:decomposition-methods].
: Сравнение методов тензорного разложения {#tbl:decomposition-methods}
| Метод | Структура | Число параметров | Интерпретируемость |
|---|---|---|---|
| CP-разложение | Сумма ранг-1 тензоров | $R \sum_{k=1}^N I_k$ | высокая |
| Tucker-разложение | Ядро и факторные матрицы | $R^N + \sum_{k=1}^N I_k R_k$ | средняя |
| TT-разложение | Последовательность ядер | $\sum_{k=1}^N I_k R_{k-1} R_k$ | низкая |
CP-разложение (Canonic Polyadic) представляет тензор в виде суммы минимального числа ранг-1 тензоров. Формула CP-разложения для тензора третьего порядка приведена в выражении ([-@eq:cp-decomposition]).
$$ \mathcal{X} \approx \sum_{r=1}^R \mathbf{a}_r \circ \mathbf{b}_r \circ \mathbf{c}_r $$ {#eq:cp-decomposition}
где $\mathcal{X}$ — исходный тензор третьего порядка;
$R$ — ранг CP-разложения;
$\mathbf{a}_r, \mathbf{b}_r, \mathbf{c}_r$ — факторные векторы по соответствующим модам;
$\circ$ — внешнее произведение векторов.
Tucker-разложение является обобщением метода главных компонент на тензоры и включает ядро, которое связывает факторные матрицы по каждой моде. Выбор метода зависит от структуры данных и требований к интерпретируемости результатов [@anandkumar2014].
# Практическое исследование алгоритмов сжатия {#sec:practice}
В данном разделе описана постановка вычислительного эксперимента и приведены результаты сравнения алгоритмов сжатия многомерных данных.
## Постановка вычислительного эксперимента {#sec:experiment}
Для оценки эффективности алгоритмов сжатия был сгенерирован синтетический тензор третьего порядка размером $50 \times 50 \times 50$. Исходный тензор содержал нормированные случайные данные с добавленным низкоранговым сигналом.
Реализация алгоритмов выполнена на языке Python с использованием библиотеки NumPy [@numpydocs] для базовых операций и тензорных вычислений. Все вычисления проводились в среде с процессором Intel Core i7 и 16 ГБ оперативной памяти.
Качество сжатия оценивалось по двум критериям: коэффициенту сжатия и относительной ошибке аппроксимации. Коэффициент сжатия вычисляется по формуле ([-@eq:compression-ratio]).
$$ C = \frac{I_1 \times I_2 \times \dots \times I_N}{\text{Число параметров разложения}} $$ {#eq:compression-ratio}
где $C$ — коэффициент сжатия;
$I_k$ — размерность исходного тензора по $k$-й моде.
Относительная ошибка аппроксимации рассчитывается как отношение нормы Фробениуса разности исходного и восстановленного тензоров к норме исходного тензора.
## Анализ результатов сжатия данных {#sec:results}
В ходе эксперимента были протестированы CP- и Tucker-разложения для различных значений ранга. Результаты сравнения приведены в таблице [-@tbl:experiment-results].
: Результаты сжатия тензора $50 \times 50 \times 50$ {#tbl:experiment-results}
| Метод | Ранг | Коэффициент сжатия | Ошибка аппроксимации, % |
|---|---:|---:|---:|
| CP | 5 | 125,0 | 12,4 |
| CP | 10 | 62,5 | 4,2 |
| Tucker | $5 \times 5 \times 5$ | 40,0 | 2,1 |
| Tucker | $10 \times 10 \times 10$ | 10,0 | 0,5 |
Анализ результатов показывает, что Tucker-разложение обеспечивает меньшую ошибку аппроксимации при сопоставимом коэффициенте сжатия за счёт наличия ядра, которое учитывает взаимодействия между компонентами факторных матриц. CP-разложение демонстрирует линейную зависимость числа параметров от ранга, что делает его предпочтительным для тензоров очень высокой размерности.
Таким образом, выбор метода сжатия должен определяться конкретными требованиями к точности восстановления данных и допустимым объёмом памяти. Параметры вычислительного эксперимента приведены в приложении А.

```python
import numpy as np

def calculate_reconstruction_error(original_tensor, reconstructed_tensor):
    norm_diff = np.linalg.norm(original_tensor - reconstructed_tensor)
    norm_orig = np.linalg.norm(original_tensor)
    return (norm_diff / norm_orig) * 100.0
```
